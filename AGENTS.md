## Documentation

For `docs/` and `README.md`:

- Write concise English learning notes. Match the target file or a similar doc.
- Read the relevant Go code first; keep names, paths, commands, and examples accurate.
- Use `##` titles and the existing heading hierarchy, fenced code with language tags, tables for comparisons, and blockquotes for notes.
- Keep explanations of how and why things work, including useful diagrams. Cut repetition, not learning context; use focused examples and link to existing material.
- Update existing topic docs when possible. Preserve unrelated content and numbered filenames; `0-*.md` holds setup and shared references.
- Use relative links. Verify uncertain claims with official references; report test success only with evidence.
- Check links, code fences, and `git diff --check`. Docs-only edits do not require running tests.
